# Template README
A repository's README file functions as the public-facing landing page for your software. We provide the following README as a minimal template; however, you are welcome to append this template with additional sections or details if they are relevant to your project.

## Research Motivation:
Please include a few sentences that describe the intended use of your software, what research question(s) motivated its development, and how the project fits into the broader context of CosmicAI.

## Compilation/Installation Instructions:
Please include a set of instructions for compiling/installing your software.  If relevant, please specify requirements for the target operating system and compiler, along with any implicit software dependencies (cmake, CUDA, PyTorch, etc.). If your project is wrapped in Python, we recommend including an option for downloading a pre-compiled binary.
